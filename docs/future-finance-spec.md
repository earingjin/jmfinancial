# 미래재무 전망 계산 명세

## 문서 상태

이 문서는 현재 승인된 미래재무 전망의 의미와 불변 규칙을 기록한다. 미확정 경제 가정이나 계산 정책을 새로 정하지 않으며, 현재 구현과 다른 내용은 구현 변경 지시가 아니라 차이 기록이다.

## 1. 지표의 목적

미래재무 전망의 공식 지표명은 **연금소득 기준 생활비 충당률**이다. 사용자가 현재 시점에서 60세·70세·80세가 되었을 때 예상되는 월 생활비를, 각 목표 나이에 실제로 수령 중인 국민연금·퇴직연금·개인연금의 월소득으로 얼마나 충당할 수 있는지 보여준다.

이 지표는 전체 자산, 순자산, 일시금 또는 자산 인출 가능액을 포함하는 종합 은퇴 준비도가 아니다. 따라서 해당 자산을 이 지표의 연금소득 분자에 포함하거나, 이 지표만으로 전체 은퇴 준비 상태를 확정해서는 안 된다.

## 2. 공식

목표 나이의 예상 월 생활비는 다음과 같다.

```text
현재 월 생활비 × (1 + 승인된 연 물가상승률)^(목표 나이 - 현재 나이)
```

연금소득 기준 생활비 충당률은 다음과 같다.

```text
목표 나이에 실제 수령 중인 월 연금소득
────────────────────────────────────── × 100
목표 나이의 예상 월 생활비
```

- 금액 단위는 현재 애플리케이션 기준인 **만원**이다.
- 생활비와 연금소득의 기간 단위는 모두 **월**이다.
- 물가상승률은 별도로 승인된 canonical 값만 사용한다.
- 분모가 0이면 0%로 변환하지 않고 산출 불가로 처리한다.

## 3. 연금 포함 규칙

아래 규칙은 국민연금·퇴직연금·개인연금 각각에 적용한다.

| 연금 상태 | 목표 나이의 월 연금소득 처리 | 결과 상태 |
| --- | --- | --- |
| 정상 수령기간 | 해당 목표 나이에 적용되는 월 수령액을 합산 | 포함 |
| 개시 전 | 월소득 0원 | 0원 |
| 종료 후 | 월소득 0원 | 0원 |
| 일시금 선택 | 월 연금소득에서 제외 | 0원 |
| 연금 없음 | 합산할 월 연금소득 없음 | 0원 |
| 개시 시점 불명 | 월 수령액이 존재하면 임의 추정 또는 0원 처리를 금지 | 산출 불가 |
| 종료 시점 불명 | 월 수령액이 존재하면 임의 추정 또는 0원 처리를 금지 | 산출 불가 |
| 월 수령액 불명 | 실제 수령액을 확인할 수 없으므로 완전한 합계로 확정 금지 | 산출 불가 |

월 연금액이 존재하지만 개시 또는 종료 시점을 확인할 수 없는 연금은 0원으로 간주하지 않는다. 확인 가능한 연금만 별도로 합산한 부분 충당률은 제공하지 않으며, 해당 목표 나이의 연금소득 합계와 충당률 전체를 `산출 불가`로 처리한다.

연금 활성기간의 경계는 **시작 시점 포함, 종료 시점 제외**다.

```text
시작 나이 ≤ 목표 시점의 해당 인물 나이 < 시작 나이 + 수령 개월 수 / 12
```

퇴직연금 또는 개인연금의 월 수령 방식을 선택하면 수령 시작 나이를 필수로 입력한다. 국민연금은 본인과 배우자의 출생연도별 승인된 수급개시 규칙과 각 수령기간을 별도로 판정한 뒤 합산한다.

## 4. 결측 상태

미래재무 전망은 다음 상태를 서로 구분해야 한다.

| 상태 | 의미 | 처리 원칙 |
| --- | --- | --- |
| 실제 0원 | 사용자가 0원을 명시했거나 유효한 계산 결과가 0원임 | 실제 값 0으로 유지 |
| 입력하지 않음 | 필요한 입력값이 비어 있음 | 정보 부족과 함께 계산 가능 여부 판정 |
| 해당 없음 | 해당 연금 또는 항목이 적용되지 않음 | 0원과 의미를 구분해 상태 보존 |
| 개시 전 | 연금은 존재하지만 목표 나이에 아직 지급되지 않음 | 월소득 0원 |
| 종료 후 | 연금은 존재하지만 목표 나이 전에 지급이 종료됨 | 월소득 0원 |
| 일시금 | 월 지급 연금이 아닌 방식으로 선택됨 | 월소득 0원, 일시금을 분자에 포함하지 않음 |
| 정보 부족 | 금액·개시·종료 등 유효성 판단 정보가 부족함 | 실제 0원으로 변환 금지, 산출 불가 사유로 기록 |
| 계산 오류 | 입력은 있으나 유효한 유한 계산 결과를 만들 수 없음 | 정보 부족과 구분하고 산출 불가 사유로 기록 |

`null`, 빈 문자열, 누락 필드 같은 정보 부족 상태를 숫자 0으로 정규화하여 완전한 충당률 계산에 사용해서는 안 된다.

## 5. 결과 구조의 의미

각 목표 나이의 결과에는 최소한 다음 의미가 필요하다.

- 목표 나이
- 목표 나이의 예상 월 생활비
- 포함된 월 연금소득 합계
- 국민연금·퇴직연금·개인연금별 금액과 포함 상태
- 연금소득 기준 생활비 충당률
- 계산 가능 여부
- 산출 불가 이유
- 적용된 가정과 그 기준일

현재 `api/_lib/futureFinance.js`는 다음과 같은 기존 필드를 반환한다.

| 필요한 의미 | 현재 구현의 대응 위치 | 문서상 주의사항 |
| --- | --- | --- |
| 목표 나이 | `targets[].age` | 기존 필드 유지 대상 |
| 예상 월 생활비 | `targets[].livingExpense` | 월 단위·만원 의미 |
| 포함된 월 연금소득 합계 | `targets[].pensionIncome` | 현재는 목표 나이별 모든 수령 유효성을 완전히 검증하지 않음 |
| 연금별 금액 | `targets[].pensionBreakdown` | 현재는 연금별 포함 상태와 불명 사유가 충분하지 않음 |
| 충당률 | `targets[].coverageRate` | 산출 불가이면 `null` |
| 표시 상태 | `targets[].status` | 현재 `good`·`warning`·`risk`·`unknown`이며 계산 가능 여부의 전체 의미를 대신하지 못함 |
| 적용 가정 | 최상위 `assumptions` | 기준일을 포함해 실제 적용 가정을 보존해야 함 |
| 결측 요약 | 최상위 `missing` | 현재 목표 나이별·연금별 사유를 표현하지 못함 |

`targets[].years`와 `targets[].balance`, 최상위 `currentAge`, `nationalPensionStartAge`, `purchasingPower`, `diagnosis`도 현재 응답에 존재한다. 이 문서는 해당 필드의 삭제·변경이나 새로운 API 필드명을 승인하지 않는다. 필요한 의미를 기존 구조에 어떻게 호환성 있게 담을지는 별도 구현 검토와 승인을 거쳐야 한다.

## 6. 승인 대기 항목

| 항목 | 현재 상태 |
| --- | --- |
| canonical 장기 물가상승률 | 연 3%로 승인(2026-08-20). `GENERAL_INFLATION_RATE`·`FUTURE_FINANCE_ASSUMPTIONS.inflationRate` 모두 이 값을 사용 |
| 위 물가상승률의 갱신주기 | 미확정 |
| 개인연금 증가율 | 미확정 |
| 퇴직연금 증가율 | 미확정 |
| 이미 지난 목표 나이의 표시 정책 | 미확정; 현행 유지 |

미확정 항목에는 임의의 기본값이나 권장값을 추가하지 않는다.

## 7. 상태 예시

다음 예시는 계산값이나 경제 가정을 새로 정하지 않고 상태 판정만 설명한다.

- **70세에 정상 수령 중인 연금:** 확인된 개시·종료 범위에 70세가 포함되면 70세의 해당 월 연금소득에 포함한다.
- **60세에는 개시 전이고 70세부터 수령하는 연금:** 60세 결과에는 0원으로 처리하고, 70세가 확인된 수령기간에 포함되면 70세 결과에 포함한다.
- **70세에 종료되어 80세에는 제외되는 연금:** 확인된 종료 규칙에 따라 70세가 수령기간에 포함되면 70세 결과에 포함하고, 종료 후인 80세 결과에는 0원으로 처리한다.
- **일시금 선택:** 모든 목표 나이의 월 연금소득에서 제외하고 0원으로 처리한다. 일시금 금액을 월 연금으로 환산하지 않는다.
- **개시 시점 불명:** 월 연금액은 존재하지만 개시 시점을 확인할 수 없으면 목표 나이의 수령 여부를 추정하지 않고 해당 결과 전체를 `산출 불가`로 처리한다.

## 8. 현재 구현 상태와 남은 차이

이 절은 현행 코드를 설명할 뿐, 이번 문서 작업에서 코드를 변경하지 않는다.

- 현재 구현은 본인·배우자의 국민연금을 각 출생연도별 개시 나이와 수령기간으로 별도 판정한다.
- 퇴직연금·개인연금의 월 수령 방식은 시작 나이를 필수로 받고 수령 개월 수로 종료 나이를 계산한다.
- 목표 나이별 활성기간은 시작 포함·종료 제외 규칙으로 판정한다.
- 월액이 양수인데 시점 정보가 부족하면 `pensionIncome`과 `coverageRate`를 `null`로 반환하고 부분 충당률을 제공하지 않는다.
- 연금별 판정 상태와 산출 불가 이유는 목표 나이 결과에 함께 제공한다.
- 현재 구현은 이미 지난 60세·70세·80세 목표를 결과 목록에서 제외한다. 이 표시 정책은 승인 전까지 변경하지 않는다.
- 현재 응답에는 순자산 구매력 참고값인 `purchasingPower`가 함께 존재하지만, 이는 `연금소득 기준 생활비 충당률`의 분자나 종합 은퇴 준비도 의미로 해석해서는 안 된다.
